# TruthStrike Quick Start - 5 Minutes to Fighting Fascist Lies

## 1️⃣ Install (30 seconds)

**Chrome/Brave:**
1. Download PROJECT_TRUTHSTRIKE folder
2. Go to `chrome://extensions/`
3. Turn on "Developer mode"
4. Click "Load unpacked"
5. Select the `extension` folder

## 2️⃣ Test It (1 minute)

Go to any of these sites and watch TruthStrike work:
- Twitter/X - Catches election denial in real-time
- Facebook - Flags anti-vax propaganda
- Reddit - Identifies climate denial
- Fox News comments - It's a goldmine of flaggable content

## 3️⃣ Use It (30 seconds per action)

When you see disinformation flagged:

**Quick Share**: Click "Share Facts" to copy a rebuttal to clipboard

**Deep Dive**: Click "Follow the Money" to see who's paying for the lie

**Report It**: Click "Report" to add to our disinformation database

## 4️⃣ Customize (2 minutes)

Click the TruthStrike icon in toolbar:
- Toggle auto-scan on/off
- View stats (lies caught, money exposed)
- Access money trail database
